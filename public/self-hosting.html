Calls on your own server.

Clearlink runs on your own computer with Node.js 20 or later. No database or account is needed. See README.md in the project folder for the complete guide.

Start locally

npm install
npm start

Open http://localhost:3001. Only this computer can join. Use PORT=3002 npm start if that port is already occupied.

Invite another device

Install Cloudflare's free cloudflared tool (on macOS: brew install cloudflared), then run:

npm run share

Open the public https address it prints, create a room and send the invitation. Keep the terminal open during the call; press Ctrl+C to stop sharing. The link exposes the app online while it runs.

Media and rooms

WebRTC encrypts audio and video in transit. The server handles membership, signalling and chat in memory. Calls are not recorded by the app. Rooms support five people and close when everyone leaves. Anyone with the invitation can join while there is space.
